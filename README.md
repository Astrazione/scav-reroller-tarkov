# Scav Loadout Reroller

Мод для **SPT + Fika**, который добавляет кнопку **Reroll SCAV** на экран выбора персонажа. Она генерирует новое снаряжение дикого перед рейдом и сразу обновляет его 3D-превью — перезапускать игру после каждого reroll не нужно.

Кнопка видна только игрокам с установленной клиентской частью. Каждый игрок меняет только своего дикого.

## Возможности

- Повторная генерация дикого через штатный генератор SPT, с учётом серверных настроек и доступных предметов.
- Обновление профиля и экипировки в превью без выхода из игры.
- Сохранение опыта, навыков и текущего таймера доступа к дикому.
- Экипировка ЧВК не меняется.
- Кнопка отображается только на экране выбора персонажа.
- Адрес сервера и сессия определяются автоматически через SPT-лаунчер.
- При ошибке загрузки можно повторить обновление профиля без нового reroll.

## Установка

Для установки нужны собранные файлы:

- `ScavReroller.Client.dll` — клиентская часть.
- `ScavReroller.Server.dll` — серверная часть.

Если у вас только исходники, сначала выполните [сборку](#сборка-из-исходников). Для установки готовых DLL не нужны исходники или .NET SDK.

Перед установкой закройте игру и сервер. Сохраните резервную копию профилей из `SPT_Runtime/user/profiles`.

### Клиентская часть

На каждом компьютере, где нужна кнопка, положите `ScavReroller.Client.dll` в:

```text
<папка игры>/
└── BepInEx/
    └── plugins/
        └── ScavReroller/
            └── ScavReroller.Client.dll
```

Папка игры — каталог с `EscapeFromTarkov.exe`. Если папки `ScavReroller` нет, создайте её.

### Серверная часть

На SPT-сервере положите `ScavReroller.Server.dll` в:

```text
<папка установки SPT>/
└── SPT_Runtime/
    └── user/
        └── mods/
            └── ScavReroller/
                └── ScavReroller.Server.dll
```

Если вы уже находитесь в каталоге с `SPT.Server.exe`, путь от него — `user/mods/ScavReroller/ScavReroller.Server.dll`.

Серверная часть устанавливается **один раз на тот SPT-сервер, к которому подключаются игроки**.

| Как вы играете | Что установить |
| --- | --- |
| Запускаете собственный SPT-сервер и играете на нём | Клиентскую и серверную части |
| Подключаетесь к общему SPT-серверу | Клиентскую часть; серверная должна быть у владельца сервера |
| Хостите рейд Fika, но используете чужой SPT-сервер | Клиентскую часть; серверная должна быть на общем SPT-сервере |

После установки запустите сервер и игру через SPT-лаунчер. При обновлении только клиентской DLL достаточно перезапустить игру.

## Использование

1. Откройте экран выбора персонажа перед рейдом.
2. Нажмите **Reroll SCAV**.
3. Дождитесь сообщения **Scav updated. Ready to raid.**
4. Проверьте новое снаряжение в превью и продолжайте подготовку к рейду.

Во время запроса и загрузки модели кнопки «Далее», «Назад» и навигация с клавиатуры блокируются.

Если появилась кнопка **Retry refresh**, нажмите её для повторной загрузки профиля и модели. Она не запускает ещё одну генерацию дикого.

## Настройки

Откройте **F12 → Scav Loadout Reroller**.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| `ShowButton` | Показывать кнопку на экране выбора персонажа | `true` |
| `ButtonCenterX` | Горизонтальное положение центра кнопки, от 0 до 1 | `0.382` |
| `ButtonY` | Вертикальное положение кнопки, от 0 до 1 | `0.66` |

Файл настроек создаётся после первого запуска:

```text
BepInEx/config/local.scav.loadout.reroller.client.cfg
```

Настраивать IP, порт или cookie не нужно. Старые параметры `BaseUrl` и `SessionCookieOverride`, если они остались в файле от предыдущих версий, больше не используются.

## Если мод не работает

**Нет настроек F12 или кнопки**

Проверьте, что DLL находится в папке той игры, которую запускает лаунчер. Если копировали установку для тестов, проверьте пути в ярлыках и настройках лаунчера. Кнопка должна появляться только на экране выбора персонажа.

В `BepInEx/LogOutput.log` должна быть запись:

```text
Loading [Scav Loadout Reroller 0.1.8]
```

**Кнопка есть, но запрос завершается ошибкой**

Проверьте установку серверной части на выбранном в лаунчере SPT-сервере. На собственном сервере должна быть запись о загрузке `Scav Loadout Reroller`. Если сервер общий, его владельцу нужно установить серверную DLL.

**Профиль или превью не обновились**

Используйте **Retry refresh**. Подробности ошибки находятся в клиентском `BepInEx/LogOutput.log` и серверных логах в `SPT_Runtime/user/logs/spt`.

При сообщении об ошибке укажите версии EFT, SPT, клиента и сервера Fika, версии обеих частей мода и приложите соответствующий фрагмент лога.

## Сборка из исходников

Для сборки нужны Windows, PowerShell, **.NET 10 SDK** и установленная игра со SPT. Скрипт берёт необходимые библиотеки из вашей установки. При первом восстановлении NuGet-пакетов может потребоваться интернет.

В корне репозитория выполните:

```powershell
.\scripts\Build-And-Install.ps1 -GameRoot 'C:\Games\SPT' -Install
```

Если сервер находится отдельно:

```powershell
.\scripts\Build-And-Install.ps1 -GameRoot 'C:\Games\SPT' -ServerRoot 'D:\SPTServer' -Install
```

`GameRoot` — каталог с `EscapeFromTarkov.exe`, `ServerRoot` — каталог, содержащий папку `SPT_Runtime`. Если `ServerRoot` не указан, используется `GameRoot`.

Без `-Install` скрипт только собирает DLL:

```text
src/ScavReroller.Client/bin/Release/net472/ScavReroller.Client.dll
src/ScavReroller.Server/bin/Release/net10.0/ScavReroller.Server.dll
```

Игровые библиотеки используются только для сборки и не должны включаться в дистрибутив мода.

## Ограничения

- Мод предназначен для подготовки к рейду. Сервер пока не блокирует reroll по состоянию Fika-лобби или рейда; не вызывайте его через сторонние инструменты во время загрузки или игры.
- Результат зависит от штатного генератора SPT и серверных модификаций. Совместимость со всеми модами на предметы и генерацию не гарантируется.
- Сохраняйте резервные копии профилей перед обновлением серверной части.

Подробности реализации и план развития: [ARCHITECTURE.ru.md](ARCHITECTURE.ru.md).

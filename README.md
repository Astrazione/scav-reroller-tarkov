# Scav Loadout Reroller

Мод для **SPT + Fika**: кнопка **Reroll SCAV** на экране выбора персонажа меняет снаряжение дикого и обновляет превью без перезапуска игры. Кнопка с глазом открывает его инвентарь. Каждый игрок меняет только своего дикого.

## Мод проверен на сборке

- **EFT:** 0.16.9.5-40743 (версия файла 0.16.9.40743).
- **SPT:** 4.1.5.
- **Fika:** клиент 2.4.3, сервер 2.4.1.

## Установка

Закройте игру и сервер. Скопируйте файлы, создав папки при необходимости:

| Файл | Куда установить |
| --- | --- |
| **ScavReroller.Client.dll** – 0.1.11 | `<папка игры>/BepInEx/plugins/ScavReroller/` |
| **ScavReroller.Server.dll** – 0.1.5 | `<папка SPT>/SPT_Runtime/user/mods/ScavReroller/` |

Клиентскую часть устанавливает каждый игрок, которому нужна кнопка. Серверную – один раз на общий SPT-сервер. Если запускаете собственный сервер, установите обе части.

Перезапустите сервер и игру через SPT-лаунчер. Адрес и сессия определяются автоматически. Видимость и положение кнопок настраиваются в **F12 -> Scav Loadout Reroller**.
